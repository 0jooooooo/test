# CLI Calculator

간단한 파이썬 커맨드라인 계산기입니다.

## 사용법

```bash
python calculator.py add 2 3   # 5.0
python calculator.py sub 5 3   # 2.0
python calculator.py mul 4 3   # 12.0
python calculator.py div 10 2  # 5.0
python calculator.py pow 2 3   # 8.0
```

지원 연산: `add`, `sub`, `mul`, `div`, `pow`

## 테스트

```bash
pip install -r requirements.txt
pytest
```
